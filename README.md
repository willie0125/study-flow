# 讀書節奏 Study Flow

給大學生使用的繁體中文讀書與時間管理筆記網站。以深色科技風整理方法、時間規劃和身心照顧，提供可搜尋、分類與點開閱讀的示範內容。

## 本機瀏覽

直接以瀏覽器開啟 `index.html` 即可，不需要安裝套件或啟動伺服器。

## 專案規則

請先閱讀 [AGENTS.md](AGENTS.md)。新增筆記時，原稿放在 `notes/`，並同步更新 `app.js` 的筆記資料。完整結構、命名和格式都列在規則文件中。

## 發布

本專案是靜態網站。將 Repository 的 GitHub Pages 設為發布 `main` 分支根目錄，即可公開瀏覽。
